### 📂 Featured Software Engineering Projects

#### 1. 🏢 Senior Citizen Payout Management System
* **Architecture:** Full-Stack (Laravel 12 Framework + MariaDB Database Server via XAMPP)
* **Scope:** Digitalizes pension scheduling, registration, document verification, and claim tracking for senior citizens in Panabo City to eliminate manual queues and data inaccuracies.
* **Technical Edge:** Solved database concurrency issues by engineering a **3-layer protection shield**: an application-level `lockForUpdate()` pessimistic lock wrapped in a `DB::transaction` block, inline `EXISTS` queries, and a fail-safe database trigger (`trg_prevent_double_claim`) for complete rollback protection.

#### 2. 💊 GamotFinder — Medical Resource Tool
* **Architecture:** Java Core (Pure Java 8, Command Line Interface, Zero External Dependencies)
* **Scope:** An offline-first reference program designed for localized Barangay Health Workers to instant-search clinical medicine details and syntax-matched symptoms without internet connectivity.
* **Technical Edge:** Implemented structural error handling wrapping `Integer.parseInt()` in a custom fallback `readInt()` system, matching stringent constraints across 17 automated testing scripts to survive malicious inputs.

#### 3. 🗳️ IC-LSG Voting Management System
* **Architecture:** Desktop client implementation (Java SE, Apache NetBeans, Swing GUI)
* **Scope:** Real-time localized campus election processing for student government registration units.
* **Technical Edge:** Prevented illegal ballot padding by mapping absolute unique user ID rules directly onto localized boolean authorization tracking tables.

#### 4. 📅 Clinical Appointment Tracker
* **Architecture:** Native Data Structures (Java, Command-Line Interface, In-Memory Arrays)
* **Scope:** Lightweight administrative medical scheduler allowing operational medical shifts, active booking requests, and administrative report logging workflows.
* **Technical Edge:** Executed full CRUD indexing mechanics purely over transient memory array records utilizing robust data validation constraints.

#### 5. 🌿 BioFlora.ph — Biodiversity Portal
* **Architecture:** Frontend Showcase (Semantic HTML5, CSS3 Custom Layouts, Bootstrap 5)
* **Scope:** A visual encyclopedia mapping native Philippine ecosystems, conservation priorities, and global species contexts.
